听弦小筑 · 古筝调音实验

调音前，先看看 21 根弦可能怎么跑音

听弦小筑把已有的古筝调音记录做成了一个可以动手试的网页。填入古筝所在环境的温度、湿度，以及它们的变化量，就能看到每根弦的预测偏差。网页里可以切换岭回归和随机森林，比较两种模型的结果。

打开预测网页 →

不用登录。网页不会自动获取天气；输入和预测都在浏览器里完成。

数据是怎么用的

整理后的数据有 64 次调音、1,344 条弦记录。前期比较了线性回归、岭回归、决策树和随机森林，也试过去掉古筝编号。现在网页里的两个模型都只用五个变量：湿度、湿度变化、温度、温度变化和弦编号。使用者填前四项，网页自动给 1～21 弦依次计算。

这个项目想预测下一次调音，所以模型比较改成了按日期向后验证。较早的 945 条记录用于训练和选模型；最后日期（8 月 20～25 日）的 399 条记录留作检验。选模型时，在早期数据上做了四轮滚动验证，共比较 39 组候选配置。

为什么现在更看好岭回归

岭回归是根据早期数据的验证结果选出的，最后那批记录没有参与选模型。下面是用最后一批记录得到的成绩；MAE 和 MSE 越低越好，R² 越高越好，R² 不是“准确率”。

模型MAEMSER²
岭回归（α ≈ 316.23）6.532474.55540.5960
随机森林10.0396179.52120.0273
训练集均值10.7603209.0188−0.1325

因此，按目前的时间验证结果，岭回归更值得优先参考；网页仍可切换两种模型。网页展示的两个模型后来又用全部历史数据重新训练；表中的数字是重新训练前的留出检验结果。

拿天气预报来用时

上面的成绩用的是当时实际测到的环境数据。若用天气预报或提前估计的数值输入，效果还没有经过实际验证。

室外天气预报只能作参考，真正要估计的是古筝所在位置的室内温湿度。原始数据也没有明确写出偏差的单位和正负号分别代表什么，所以网页沿用原始数值，不把预测值解释成具体的拧弦幅度或方向。

原始日期只有月、日，验证时暂按同一年排列。这批记录也曾用于前期探索，最后的留出结果还不能代替用新数据做的验证。

代码与资料

模型用 Python 和 scikit-learn 训练，再导出到网页中运行。开发过程中使用了 AI 辅助整理代码、页面和文字。仓库里保留了原始 Excel；仓库公开后，这份文件也会随之公开。

TINGXIAN · ENGLISH SUMMARY

About this project

Tingxian estimates pitch drift for each of a guzheng's 21 strings from temperature and humidity inputs. Visitors can compare ridge regression with a random forest. In a date-ordered holdout using measured conditions, ridge regression reached an MAE of 6.5324 in the source data's unspecified units. Performance with weather forecasts or indoor estimates has not yet been tested.
