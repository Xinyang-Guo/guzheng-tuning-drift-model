TINGXIAN · MUSIC × ENVIRONMENT × MACHINE LEARNING

What can the weather tell us about a guzheng’s pitch drift?

Tingxian is an experimental exploration of the relationship between environmental conditions and pitch deviation across the 21 strings of a guzheng. It brings model comparison and a playable, pixel-art-inspired interface into one project.

Try the 21-string explorer →

No account is needed. Both models run in your browser; entered conditions are not sent to a prediction server. Weather is entered manually, not fetched automatically.

From an observation to a testable model

The project links tuning-session records with environmental measurements, compares linear regression, ridge regression, decision trees and random forests, and examines the effect of removing instrument identity. After clarifying that the intended use is future tuning, evaluation changes from a random session split to chronological validation.

The deployed models use five features: relative humidity, humidity change, temperature, temperature change, and string number. The interface collects four environmental values and supplies each string number automatically.

Chronological evaluation

The cleaned dataset contains 1,344 string-level records from 64 tuning sessions. Earlier dates supply 945 development records; the final dates, August 20–25, supply 399 holdout records. Four expanding-window validation folds compare 39 candidates (156 fold fits). Same-day records remain together.

The displayed models were subsequently refit on all available history; the table reports the earlier holdout evaluation, not a new evaluation of these refitted models.

What the evidence does—and does not—show

These are retrospective results using measured environmental conditions. They do not establish accuracy when using future weather forecasts or indoor-environment estimates.
  • Model errors vary substantially between time folds; more future sessions are needed.
  • The source dates contain month and day but no year. They are interpreted as one year's chronology.
  • The same historical records had already been explored in earlier experiments; the holdout is not an untouched external dataset.
  • Outdoor weather forecasts do not directly describe indoor instrument conditions. This is a conditional prediction tool, not an automatic forecasting service.
  • The source does not explicitly establish the deviation unit or sign convention. The app therefore uses the original data units and does not prescribe physical tuning adjustments.

Implementation and contribution transparency

Python and scikit-learn support preprocessing, training and evaluation. The public app uses exported numerical model parameters and JavaScript inference. AI tools assisted with code, interface development, testing and documentation. This project page does not claim that every implementation step was completed unaided.

The public release includes trained inference parameters and aggregate results. Raw experimental spreadsheets and row-level records are withheld by default. Public model parameters remain inspectable by visitors.

听弦小筑 · 研究手记

用环境变化，理解二十一弦的跑音

听弦将古筝调音记录与温湿度信息关联，比较多种回归模型，并把结果做成可交互的像素风网页。项目从随机划分实验，进一步转向更符合“未来调音”用途的时间顺序验证。

当前网页支持五变量随机森林与岭回归：输入湿度、湿度变化、温度、温度变化，模型依次预测 1～21 弦，不使用古筝编号。预测全部在浏览器内完成，无需本地 Python 服务。

在现有时间验证中，岭回归的留出 MAE 为 6.5324，R² 为 0.5960，优于本次搜索中的随机森林。这不是“59.6% 的准确率”，也不能直接与旧随机划分下的成绩比较。

这些成绩使用实测环境。实际用途依赖天气预报或环境估计，仍需收集预测发出时的环境估计及后续调音结果，进行真正的前瞻验证。页面不自动获取天气，也不直接给出拧弦操作量。

代码、页面、测试和文档整理使用了 AI 辅助；申请展示时应如实说明自己的研究设计、采集、分析与工具使用情况。公开版默认不含原始 Excel 和逐条实验记录。
