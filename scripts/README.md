# Export and verification

The committed `docs/assets/models.json` is ready to use. These maintenance scripts
require the research dependencies and trusted local model artifacts.

1. Install `requirements-dev.txt` and run `python -m playwright install chromium`.
2. With an authorized workbook in `data/`, run `python src/guzheng_future_validation.py`
   to create the required evaluation metrics, then start `python web/server.py` once
   to fit both models and create `output/web_random_forest/` and `output/web_ridge/`.
3. Run `python scripts/export_browser_models.py` to refresh the browser parameters.
4. Serve the repository with `python -m http.server 8870`, then run
   `python scripts/test_static_site.py --url http://127.0.0.1:8870/docs/`.

The test compares browser and scikit-learn outputs, including threshold boundaries,
then checks switching models, offline prediction after loading, validation and CSVs.
Verification from the prepared release is in `results/browser_verification.json`.

Python 3.14 was used for the recorded environment. Research figures need an installed
font with Chinese glyphs; scripts fall back to the system font outside macOS.
The research sources reflect the latest workflow. Historical six-feature experiments
are retained as aggregate results; they are not all regenerated by the latest scripts.
